# SIAT AI Agent — сводка (26.11.2026)

## Что это
Агент по официальной статистике Узбекистана. Он берёт данные с siat.stat.uz через открытый JSON API без ключа
(база `https://siat.stat.uz/api`), хранит их в PostgreSQL и отвечает на вопросы на узбекском (латиница и кириллица)
и русском. Это отдельный проект, не Qonunchi.

Главное правило: цифры только из SQL, LLM их не придумывает. В ответе всегда есть индикатор, регион, период,
таблица, % изменения, источник SIAT, код датасета и дата обновления.

## Где что лежит
- **Код:** `siat_agent/`, то же самое в `siat_agent.zip`. Подробности в `siat_agent/README.md`.
- **Установщик для Mac:** `install_siat_mac.sh`, код вшит внутрь. Ставит в `~/siat_agent`. Шаги:
  1. Docker-контейнер `siat-pg` (postgres:16, порт 5433).
  2. Python 3.13 venv.
  3. Ключ OpenAI в `.env`.
  4. Данные SIAT.
  5. Тестовый вопрос.
  6. Telegram-бот (launchd `uz.siat.bot`).
- **Отчёт о качестве данных:** `siat_agent/data/quality_report.md`.
- **Виджет расходов OpenAI** в строке меню (SwiftBar, расходы по ключам ai-yurist и siat): `openai_widget/`. Работает.

## Что сделано
- **Данные:** скачаны все 2 085 годовых индикаторов SIAT по регионам. В базе 2 057 индикаторов и 242 134 значения за 1990–2026 годы по 15 регионам.
- **Поиск индикатора** по всему каталогу (`siat_search.py`). Предпочитает основной показатель и показатели с данными по нужному региону. В режиме LLM модель получает 25 лучших кандидатов. Если поиск не уверен, агент предлагает варианты, а не гадает.
- **Проверки качества** (`check_data.py`): 0 ошибок, 3 предупреждения (см. «Известные ограничения»).
- **Контрольные вопросы** (`eval/run_eval.py`):
  - 31/31 в режиме правил, каждая цифра сверяется с живым SIAT.
  - Те же 31/31 под ролью только для чтения `siat_reader`.
  - В режиме LLM 31/31 на Mac (26.11.2026, после защиты от выбора нескольких индикаторов в `query_agent.py`).
- **Telegram-бот** (`telegram_bot.py`): не больше 30 вопросов в час на пользователя, можно включить белый список.
- **Обновление данных** одной командой: `./update_data.sh`. Повторный запуск качает только индикаторы, обновлённые на SIAT.
- **LLM:** OpenAI `gpt-4.1-mini`. Ключ «siat» хранится только в `~/siat_agent/.env` на Mac.

## Известные ограничения
- 8 индикаторов с периодом в виде учебного года (`2016/2017`) не загружаются.
- 20 индикаторов пустые на самом SIAT.
- У 13 индикаторов в паспорте SIAT нет единицы измерения.
- Многие индикаторы есть только по республике (1700). Если о таком спросить по области, агент прямо говорит, какие данные есть.
- Квартальные и месячные данные не загружены: на SIAT они нарастающим итогом. Например, мясо (go‘sht) есть только поквартально.
- SIAT отвечает ошибкой 429 на частые запросы к `/table/download/`. Там только ссылки на файлы, поэтому пропустить их не страшно.
- На Mac Homebrew python3 — это 3.15 alpha, и pip в нём не работает. Установщик берёт 3.13 из /Library/Frameworks.
